# Security Policy

Do not report security issues in public GitHub issues.

Please use GitHub private vulnerability reporting for this repository
(`Security` → `Report a vulnerability`), or contact the repository maintainer
through the contact method listed in their GitHub profile.

Include: affected version, reproduction steps and impact. Do not attach real
tokens, maFile contents, encryption keys or personal data.

Supported versions: latest published release only.

Rotate credentials immediately if a bot token, `ENCRYPTION_KEY` or maFile was
exposed; see the "При утечке" section in [README.md](README.md).
